```rust
fn parse_contacts_response(&self, xml: &str) -> Result<Vec<Contact>> {
    let doc = roxmltree::Document::parse(xml)
        .map_err(|e| Error::Server(format!("Failed to parse XML: {e}")))?;
    let dav_ns = "DAV:";
    let carddav_ns = "urn:ietf:params:xml:ns:carddav";
    let mut contacts = Vec::new();
    for response in doc.descendants().filter(|n| n.has_tag_name((dav_ns, "response"))) {
        if let Some(vcard_data) = response
            .descendants()
            .find(|n| n.has_tag_name((carddav_ns, "address-data")))
            .and_then(|n| n.text())
            && let Some(contact) = parse_vcard(vcard_data)
        {
            contacts.push(contact);
        }
    }
    contacts.sort_by(|a, b| a.name.to_lowercase().cmp(&b.name.to_lowercase()));
    Ok(contacts)
}
```

**Add two new variants** to the `Error` enum in `src/error.rs`, after the existing `EmailNotFound(String)` variant (line ~32):

```rust
#[error("Contact not found: {0}")]
ContactNotFound(String),

#[error("Contact conflict for '{id}': sent ETag '{sent_etag}', server has '{server_etag:?}'")]
ContactConflict {
    id: String,
    sent_etag: String,
    server_etag: Option<String>,
},
```

Per D-04: `ContactNotFound(String)` is a single-string tuple variant carrying the contact UID, consistent with `EmailNotFound(String)` and `MailboxNotFound(String)`.

Per D-03: `ContactConflict` is a struct variant with three named fields:
- `id: String` — the contact UID
- `sent_etag: String` — the ETag the client sent in the If-Match header
- `server_etag: Option<String>` — the server's current ETag if available (Option because not all 412 responses include it)

The `#[error(...)]` format string uses `{server_etag:?}` (Debug format) because `server_etag` is `Option<String>` — this prints `Some("...")` or `None` which is appropriate for diagnostic output.

These variants follow the existing thiserror patterns:
- `ContactNotFound` mirrors `EmailNotFound` (tuple variant with `#[error("... {0}")]`)
- `ContactConflict` mirrors `Jmap` (struct variant with named fields in `#[error("...")]`)
