    **GREEN phase:** Implement the following functions in src/carddav/mod.rs:

    1. `fn escape_value(s: &str) -> String` (private helper):
       - Replace `\` with `\\` FIRST (to avoid double-escaping)
       - Then replace `;` with `\;`
       - Then replace `,` with `\,`
       - Then replace `\n` (newline char U+000A) with literal two-char sequence `\n`

    2. `fn fold_line(line: &str) -> String` (private helper):
       - If line.len() <= 75: return format!("{}\r\n", line)
       - First physical line: max 75 bytes. Find fold point at or before 75, walking backward with is_char_boundary() if needed
       - Continuation lines: max 74 bytes of content (75 total minus 1 leading space). Same is_char_boundary() safety
       - Join with "\r\n " (CRLF + space) between chunks
       - End with "\r\n"

    3. `pub fn serialize_vcard(contact: &Contact) -> String` (public function):
       - Build lines vector, then fold each line, then join
       - Line order per D-05 and Research Pattern 5:
         a. "BEGIN:VCARD"
         b. "VERSION:3.0"
         c. "UID:{contact.id}" -- use contact.id directly (caller provides UUID v4 for new contacts per VCARD-03)
         d. "FN:{escape_value(&contact.name)}"
         e. N property per D-01/D-02: split contact.name on whitespace, first token = given, last token = family (if >1 token), middle tokens joined. Single token: given only, family empty. Format: "N:{escape(family)};{escape(given)};{escape(middle)};;"
         f. For each email: "EMAIL;TYPE={label}:{email}" if label is Some, else "EMAIL:{email}"
         g. For each phone: "TEL;TYPE={label}:{number}" if label is Some, else "TEL:{number}"
         h. If organization is Some: "ORG:{escape_value(org)}"
         i. If title is Some: "TITLE:{escape_value(title)}"
         j. If address is Some per D-03: "ADR:;;{escape_value(street)};;;;;" (6 semicolons total: 2 before street, 4+1 after = ;;street;;;;;)

            IMPORTANT: Count carefully. ADR has 7 components separated by 6 semicolons:
            `PO Box ; Extended ; Street ; Locality ; Region ; Postal Code ; Country`
            Format: `ADR:;;{street};;;;;`
            That is: empty PO`;`empty Extended`;`street`;`empty Locality`;`empty Region`;`empty Postal`;`empty Country
            = `;;street;;;;;` which has 6 semicolons total.

         k. If notes is Some: "NOTE:{escape_value(notes)}"
         l. "END:VCARD"
       - For each line, apply fold_line() to get the folded output with CRLF
       - Concatenate all folded lines into final String
       - Return the String directly (infallible per Research recommendation)

    4. Add `use uuid::Uuid;` import at the top of the file (for use by callers in Phase 3 -- the serialize_vcard function itself uses contact.id, not Uuid::new_v4 directly, but we validate the import compiles)
