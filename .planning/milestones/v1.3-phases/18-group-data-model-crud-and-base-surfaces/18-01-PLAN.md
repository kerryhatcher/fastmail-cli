```rust
/// A contact group parsed from a group vCard (X-ADDRESSBOOKSERVER-KIND:group)
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct ContactGroup {
    /// Unique ID (from UID property)
    pub id: String,
    /// Display name (FN property)
    pub name: String,
    /// Member contact UIDs (extracted from X-ADDRESSBOOKSERVER-MEMBER:urn:uuid:<uid> lines)
    pub member_uids: Vec<String>,
    /// Server-assigned resource URL
    pub href: Option<String>,
    /// HTTP ETag for optimistic concurrency
    pub etag: Option<String>,
}
```

3. In parse_vcard() (line 593), add an early return check after the unfold_vcard call. Scan lines for X-ADDRESSBOOKSERVER-KIND:group using case-insensitive comparison. If found, return None immediately before any Contact field parsing.

4. Add parse_group_vcard() function (private, next to parse_vcard). It unfolds the vCard, iterates lines, extracts:
   - UID → id (split_once on ':', take value)
   - FN → name (split_once on ':', take value, apply unescape_value)
   - X-ADDRESSBOOKSERVER-KIND:group → is_group flag (case-insensitive eq)
   - X-ADDRESSBOOKSERVER-MEMBER:urn:uuid:<uid> → push uid to member_uids
   Returns None if !is_group or name is empty. If id is empty, generate with Uuid::new_v4().

5. Add serialize_group_vcard() as a pub function (mirrors serialize_vcard). Emits lines:
   BEGIN:VCARD, VERSION:3.0, UID:{id}, FN:{escape_value(name)}, X-ADDRESSBOOKSERVER-KIND:group,
   then for each member_uid: X-ADDRESSBOOKSERVER-MEMBER:urn:uuid:{uid},
   then END:VCARD. Apply fold_line() to each and collect.

6. Add parse_groups_from_xml() function (private, mirrors parse_contacts_from_xml). Same XML parsing logic (dav_ns "DAV:", carddav_ns "urn:ietf:params:xml:ns:carddav"), iterates response elements, extracts href/etag/address-data, calls parse_group_vcard() instead of parse_vcard(). Collects only the Some results. Sorts by name (lowercase).

7. Add build_group_href() function (private): same as build_contact_href — `format!("{trimmed}/{group_id}.vcf")`.

8. Add map_group_write_response() function (private, parallel to map_write_response). Takes group_id: &str, sent_etag: Option&lt;&str&gt;, status, headers, body. Returns Result&lt;Option&lt;String&gt;&gt;. Success returns header_value(headers, ETAG). 412 returns GroupConflict, 404 returns GroupNotFound, other returns Error::Server.

Add 6 async methods to the CardDavClient impl block, following the exact patterns of the existing contact methods:

1. **list_groups(&self) -> Result&lt;Vec&lt;ContactGroup&gt;&gt;**: Mirrors list_contacts flow. Call self.list_addressbooks().await, then for each addressbook call self.fetch_addressbook_groups(&ab.href).await (new private helper). Collect results using a collect_partial_groups helper (mirrors collect_partial_contacts). The fetch_addressbook_groups method sends the same REPORT body as list_contacts (all vCards), but calls parse_groups_from_xml instead of parse_contacts_from_xml.

2. **get_group_by_id(&self, group_id: &str) -> Result&lt;ContactGroup&gt;**: Call list_groups(), find first where group.id == group_id. If not found, return Err(Error::GroupNotFound(group_id.to_string())).

3. **get_group_by_name(&self, name: &str) -> Result&lt;ContactGroup&gt;**: Call list_groups(), collect all where group.name == name (case-sensitive). 0 matches -> GroupNotFound(name), 1 match -> Ok(group), 2+ matches -> GroupAmbiguous(name).

4. **create_group(&self, addressbook_href: &str, group: &ContactGroup) -> Result&lt;ContactCreateResult&gt;**: Mirrors create_contact exactly. Build href with build_group_href, serialize with serialize_group_vcard, PUT with Content-Type text/vcard, If-None-Match: *, call map_group_write_response, extract location from headers.

5. **rename_group(&self, href: &str, etag: &str, group: &ContactGroup, new_name: &str) -> Result&lt;String&gt;**: Create a new ContactGroup with same id, member_uids, href, etag but name = new_name.to_string(). Serialize with serialize_group_vcard. PUT to self.base_url + href with Content-Type text/vcard, If-Match: etag. Call map_group_write_response. Return the new ETag string (unwrap with default empty string if None).

6. **delete_group(&self, href: &str, etag: &str, group_id: &str) -> Result&lt;()&gt;**: Mirrors delete_contact exactly. DELETE to self.base_url + href with If-Match: etag. Call map_group_write_response with the group_id. Map Ok(Some/None etag) to Ok(()).

Also add the private helper methods:
- fetch_addressbook_groups(&self, addressbook_href: &str) -> Result&lt;(String, Vec&lt;ContactGroup&gt;)&gt; — identical structure to the existing per-book contact fetch but calls parse_groups_from_xml.
- collect_partial_groups(results: Vec&lt;Result&lt;(String, Vec&lt;ContactGroup&gt;)&gt;&gt;) -> Vec&lt;ContactGroup&gt; — mirrors collect_partial_contacts.

For the member resolution optimization (used by CLI get and MCP getGroup): add a helper method resolve_group_members(&self, group: &ContactGroup) -> Result&lt;Vec&lt;Contact&gt;&gt; that calls list_contacts on all addressbooks once, then filters in-memory by member_uids. This avoids N+1 HTTP calls. The method: get all contacts via search_contacts("") or list all, then filter where contact.id is in group.member_uids.
