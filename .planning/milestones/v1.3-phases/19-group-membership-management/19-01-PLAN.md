<threat_model>
## Threat Model (ASVS Level 1)

**Assets:** Contact group membership data on Fastmail CardDAV server
**Trust boundary:** CardDavClient <-> Fastmail server (HTTPS + Basic Auth, already established)

| Threat | Severity | Mitigation |
|--------|----------|------------|
| Race condition drops members on concurrent writes | HIGH | ETag-guarded PUT with retry-on-412 loop (max 3 retries) — re-fetches group state on each retry |
| Adding non-existent contact UID creates orphan reference | MEDIUM | Validate contact_uid via get_contact_by_id() before entering retry loop — fail fast |
| Duplicate MEMBER lines corrupt group vCard | MEDIUM | Idempotency check: skip if member_uids already contains contact_uid |
| Retry loop infinite spin | LOW | Hard cap at MAX_RETRIES=3, then return GroupConflict error |

No new auth surfaces. Reuses existing CardDavClient authentication (Basic Auth over HTTPS).
</threat_model>

    **`pub async fn add_group_member(&self, group_id: &str, contact_uid: &str) -> Result<ContactGroup>`**

    Implementation (follows rename_group pattern from lines 556-596 but with retry loop):
    1. Call `self.get_contact_by_id(contact_uid).await?` to validate contact exists (fail fast with ContactNotFound)
    2. Define `const MAX_RETRIES: u8 = 3;`
    3. Loop `for attempt in 0..MAX_RETRIES`:
       a. `let group = self.get_group_by_id(group_id).await?;`
       b. Extract `href` from `group.href` (return GroupNotFound if None)
       c. Extract `etag` from `group.etag` (return GroupConflict with empty sent_etag if None)
       d. Idempotency check: `if group.member_uids.contains(&contact_uid.to_string()) { return Ok(group); }`
       e. Clone group: `let mut updated = group.clone();` — add `updated.member_uids.push(contact_uid.to_string());`
       f. Build URL: `format!("{}{}", self.base_url, href)`
       g. Serialize: `let vcard = serialize_group_vcard(&updated);`
       h. PUT with `self.client.put(&url).basic_auth(&self.username, Some(&self.app_password)).header("Content-Type", "text/vcard; charset=utf-8").header(IF_MATCH, etag).body(vcard).send().await?`
       i. Extract status, headers (clone), body text
       j. Match on `map_group_write_response(group_id, Some(etag), status, &headers, &body)`:
          - Ok(new_etag) -> set `updated.etag = new_etag.or_else(|| Some(etag.to_string()));` and `return Ok(updated);`
          - Err(Error::GroupConflict { .. }) if attempt < MAX_RETRIES - 1 -> `debug!(attempt, group_id, "ETag conflict on add_group_member, retrying"); continue;`
          - Err(e) -> `return Err(e);`
    4. After loop exhaustion: `Err(Error::GroupConflict { id: group_id.to_string(), sent_etag: String::new(), server_etag: None })`

    Add `#[instrument(skip(self))]` attribute.

    **`pub async fn remove_group_member(&self, group_id: &str, contact_uid: &str) -> Result<ContactGroup>`**

    Identical structure to add_group_member except:
    - No `get_contact_by_id` validation (removing a reference to a deleted contact should work)
    - Idempotency inverts: `if !group.member_uids.contains(&contact_uid.to_string()) { return Ok(group); }`
    - Mutation: `updated.member_uids.retain(|uid| uid != contact_uid);` instead of push
    - Debug message: "ETag conflict on remove_group_member, retrying"
