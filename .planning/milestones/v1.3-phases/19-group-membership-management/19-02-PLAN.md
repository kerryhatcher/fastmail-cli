## Threat Model (ASVS Level 1)

**Assets:** Contact and group data on Fastmail CardDAV server
**Trust boundary:** CLI user input -> CardDavClient (validated by transport layer)

| Threat | Severity | Mitigation |
|--------|----------|------------|
| Partial failure on --group leaves orphan contact | MEDIUM | Report partial success with created contact ID and retry instructions — user can manually add to group |
| Group name injection via CLI arg | LOW | Group names pass through resolve_group which uses exact match against server-side data, no injection vector |

No new auth surfaces. Input validation delegated to clap (required args) and CardDavClient methods (contact/group existence).
</threat_model>
