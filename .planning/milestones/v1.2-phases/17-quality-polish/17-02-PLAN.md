Replace `DefaultHasher` in `hash_id()` with `SipHasher13` from the `siphasher` crate so fallback contact IDs are stable across Rust compiler versions. Add a golden-value test that pins the exact output for a known input, recording the stable contract per D-04.

Purpose: DefaultHasher's algorithm is allowed to change between Rust releases (and did change between 1.7 and 1.13). Contact IDs derived from it would shift silently on toolchain upgrade, corrupting references held by callers. SipHasher13 with a fixed seed is deterministic forever.
