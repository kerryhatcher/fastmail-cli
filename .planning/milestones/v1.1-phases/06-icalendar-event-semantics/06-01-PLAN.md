# Plan 06-01: iCalendar Event Semantics

## Goal

Implement local event parsing and serialization before relying on network CRUD.

## Tasks

1. Add `CalendarEvent` and related attendee/recurrence/reminder/time structs.
2. Parse `VEVENT` resources from CalDAV `calendar-data`.
3. Serialize new and updated events back into valid `VCALENDAR`/`VEVENT` payloads.
4. Cover all-day, timezone-bearing, recurrence, attendee, and reminder cases with unit tests.

## Verification

- `cargo test`
- Round-trip fixture coverage for representative event payloads.
