# Plan 08-01: CLI Calendar Experience

## Goal

Add first-class CLI calendar/event commands built on the new CalDAV helpers.

## Tasks

1. Extend `src/main.rs` with `calendars` and `events` subcommands.
2. Support default today-range event listing, `--week`, and explicit `--start` / `--end`.
3. Support calendar create/update/delete and event get/create/update/delete flows.
4. Keep outputs JSON and include IDs/href/etag metadata needed by later edits/deletes.

## Verification

- `cargo test`
- `cargo run -- --help` style compile coverage through clap derive.
