# Plan 05-01: CalDAV Discovery Foundation

## Goal

Implement the Fastmail CalDAV foundation needed by all later calendar phases: calendar-home discovery, calendar collection listing, stable calendar identifiers, and shared WebDAV write helpers.

## Tasks

1. Add a sibling `src/caldav/mod.rs` module that mirrors the existing CardDAV client structure.
2. Reuse the existing username + app-password config contract instead of introducing a new calendar config section.
3. Parse calendar-home and calendar collection XML responses into stable `Calendar` models carrying `id`, `name`, `color`, `href`, and server metadata.
4. Add unit tests for discovery parsing, default-calendar detection, and helper behavior.

## Verification

- `cargo test`
- Confirm `Calendar` surfaces preserve stable machine IDs and CalDAV href/etag metadata for downstream CRUD phases.
