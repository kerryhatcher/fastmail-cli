# Plan 11-01: CLI Attendee Clearing Parity

## Goal

Add an explicit CLI update path for clearing attendees so terminal behavior matches the existing event patch semantics already available below the CLI layer.

## Contract Decision

- `events update --clear-attendees` sends an intentional empty attendee list.
- `events update --attendee ...` continues to replace attendees with the supplied set.
- Supplying both `--attendee` and `--clear-attendees` is invalid.
